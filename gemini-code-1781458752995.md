Rol: Desarrollador Frontend Senior y Diseñador UI/UX. Contexto: Desarrollo
clásico (HTML5, CSS3 puro y JavaScript Vanilla). Proyecto: "TicketFlick".
Objetivo: Implementar una pantalla de carga (Preloader) con animación fluida y
el logotipo de la marca que mitigue el retraso visual (FOUC) al navegar entre
los diferentes archivos HTML del sitio.

Instrucciones de Implementación Técnica:

1. ESTRUCTURA DEL PRELOADER (HTML5)

- Crea un bloque de cobertura total al inicio del `<body>` en las páginas
  indicadas.
- Estructura interna: Debe contener un contenedor central con el logotipo de la
  marca escrito limpiamente como "TicketFlick" y un elemento dedicado para el
  bucle de carga (spinner/loader animation).

2. ESTÉTICA MINIMALISTA Y PROFESIONAL (CSS3)

- El panel de carga debe ocupar el 100% de la pantalla
  (`width: 100vw; height: 100vh;`) con un `position: fixed; top: 0; left: 0;` y
  un `z-index` lo suficientemente alto (ej. 9999) para bloquear cualquier
  destello desestructurado de la página de fondo.
- Aplica la paleta vinotinto/oscura y un elegante acabado Glassmorphism de fondo
  si es necesario, o un fondo sólido oscuro premium para ocultar la carga.
- Diseña un bucle de carga (spinner o barra de progreso infinita) usando
  únicamente `@keyframes` de CSS para que sea ultra ligero y suave (60fps).

3. CONTROL DE TRANSICIÓN (JavaScript Vanilla)

- Añade un mini-script optimizado que escuche el evento
  `window.addEventListener('load', ...)` para garantizar que el preloader solo
  se desvanezca (`opacity: 0` con transiciones de CSS) una vez que TODO el HTML,
  CSS e imágenes del destino estén listos en el navegador.
- Asegúrate de destruir el nodo con `.remove()` tras finalizar la transición de
  opacidad para que no interfiera con los clics del usuario.
